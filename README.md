# Replication Data and Code for: "The Illusion of Harmony"

This repository contains the de-identified raw data and the analysis code used in the research article: **"The Illusion of Harmony: Cognitive Tension, Disciplinary Patterns, and Evolution Acceptance Among Science Educators"** (currently under review).

## Overview
The study explores the conceptual ecology of evolution acceptance among Greek secondary science educators (Biologists, Geologists, Physicists, and Chemists). It introduces the **Deep Time Error (DTE)** index and utilises structural equation modelling (CFA) and multiple regression to examine the interplay between biological knowledge, personal religious faith, and perceived science-religion compatibility.

## Repository Contents

* `dte_raw_deidentified.xlsx`: The raw, de-identified dataset containing educators' responses. (Demographic variables that could permit participant re-identification have been aggregated or removed to ensure anonymity).
* `reproduce_dte_analysis.py` : The Python code used to process the data, calculate the Deep Time Error (DTE) index, and generate the regression models.
* `README.md`: This descriptive file.

## Usage
To reproduce the calculation of the Deep Time Error (DTE) index and the subsequent analyses, ensure you have Python 3.x installed along with the following libraries: `pandas`, `numpy`, `scipy`, and `statsmodels`.
