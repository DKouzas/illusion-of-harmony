# Replication Data and Code for: "The Illusion of Harmony"

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24203533.svg)](https://doi.org/10.5281/zenodo.24203533)

This repository contains the supplementary documentation, de-identified raw data, and analysis code used in the research article: **"The Illusion of Harmony: Cognitive Tension, Disciplinary Patterns, and Evolution Acceptance Among Science Educators"** (currently under review).

## Repository Contents

* `Supplementary_Material_DTE.pdf`: The detailed document explaining the calculation, scoring, and analysis workflow for the Deep Time Error (DTE) index, including missing-data treatment and reference values.
* `dte_raw_deidentified.xlsx`: The raw, de-identified dataset containing educators' chronological estimates. (Demographic variables that could permit participant re-identification have been removed to ensure anonymity).
* `reproduce_dte_analysis.py` : The Python script used to process the data, calculate the DTE index, and generate the regression models.
* `README.md`: This descriptive file.

## Usage
To reproduce the calculation of the Deep Time Error (DTE) index, follow the workflow outlined in the Supplementary Material PDF. Ensure you have Python 3.x installed along with the libraries: `pandas`, `numpy`, and `scipy`.
